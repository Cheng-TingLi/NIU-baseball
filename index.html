📖 使用說明

  1. 到「選手名單」新增所有打者與投手姓名。
  2. 到「打擊輸入」或「投手輸入」，選擇日期與選手，填入該場數據後按「新增此筆」。輸入錯誤可按該筆的「改」載入後修改再「儲存修改」。
  3. 「打擊總結」與「投手總結」會即時自動加總並計算進階數據。
  4. 到「文字分享」可產生單一或全部選手的文字報告，可複製、或「存成文字檔（.txt）」給朋友，也可讀取之前的文字檔查看。
  5. 資料會自動暫存在瀏覽器。選手名單頁的「存檔／讀檔」是備份完整數據用（JSON）；文字分享頁的存讀則是純文字報告。
  6. 可隨時刪除單筆紀錄或清除所有資料重新開始。

打擊率公式

  • 打擊率 BA = 安打 ÷ 打數
  • 上壘率 OBP = (安打 + 保送 + 觸身) ÷ (打數 + 保送 + 觸身 + 犧牲飛球)
  • 長打率 SLG = 壘打數 ÷ 打數
  • OPS = 上壘率 + 長打率
  • 壘打數 = 一壘安打×1 + 二壘×2 + 三壘×3 + 全壘打×4

投手公式

  • 防禦率 ERA = (責失分 × 9) ÷ 投球局數
  • WHIP = (保送 + 被安打) ÷ 投球局數
  • 局數輸入範例：6.0 = 6局、5.1 = 5又1/3局、5.2 = 5又2/3局
